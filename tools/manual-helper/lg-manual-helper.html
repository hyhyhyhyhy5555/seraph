로컬 자동 저장 활성화됨

1. 검색 및 복사 요령

  • 카테고리 칩을 선택해 LG 사이트 카테고리 변경 횟수를 줄이세요.
  • 주 모델명을 클릭하면 마침표(.) 앞 순수 모델명이 바로 복사됩니다.
  • 검색 결과가 없으면 대체코드 → 접두어(자동완성) 순서로 시도하세요.

2. 다운로드 PDF 선택 기준

  • 필수: 한국어 정식 사용설명서 PDF(본편)
  • 제외: 영문 설명서, 간단 설명서(본편 있을 때), 설치설명서 단독, 소프트웨어/펌웨어
  • 같은 시리즈에서 이미 받은 MFL*.pdf와 문서번호가 같으면 중복PDF로 표시하세요.

3. 파일명 유지 & macOS 빠른 저장

  • LG 원본 파일명(예: MFL71892301.pdf)은 바꾸지 말고 그대로 저장하세요.
  • 그룹 상단 폴더 경로 복사 클릭 → 저장 창에서 Cmd + Shift + G → 붙여넣기 → Enter.
  • 작업 중간·완료 시 진행결과 CSV 내보내기로 백업해 두세요.
