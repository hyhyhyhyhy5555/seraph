# ADR 0001: 개발자용 저장소 오케스트레이터 범위

- 상태: 승인됨
- 날짜: 2026-11-22

## 맥락

세라프에는 제품 사용자를 위한 RAG 채팅이 이미 존재한다. 이번 설계 대상이 제품 AI인지 개발 자동화인지 먼저 구분해야 이후 역할, 인증, 도구와 안전 경계를 결정할 수 있다.

## 결정

첫 번째 오케스트레이션 대상은 프로젝트 소유자가 사용하는 개발 작업이다. 오케스트레이터는 관련 코드와 문서를 조사해 변경 계획을 제시하고, 사용자가 그 계획을 승인한 뒤에만 코드를 변경하고 검증한다.

## 결과

- 기존 제품 RAG 흐름은 이번 오케스트레이터의 직접 구현 대상이 아니다.
- 승인 전 단계는 읽기 전용으로 제한한다.
- 기술 스택과 세부 실행 방식은 후속 인터뷰에서 결정한다.
