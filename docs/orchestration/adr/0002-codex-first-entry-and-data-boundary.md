# ADR 0002: Codex 중심 진입점과 모델 전달 경계

- 상태: 승인됨
- 날짜: 2026-11-22

## 맥락

오케스트레이터를 Codex 대화 안에서 사용할지, 별도 터미널 프로그램으로 제공할지에 따라 인증과 상태 관리 구조가 달라진다. 또한 모델에 전달할 수 있는 저장소 자료의 기본 범위가 필요하다.

## 결정

- 첫 버전은 공식 Codex 대화와 프로젝트 명령을 주 진입점으로 사용한다.
- 한 번 승인된 계획 한 건을 구현하고 검증한 뒤 종료한다.
- 필요한 코드와 프로젝트 문서의 최소 구간은 공식 Codex 모델에 전달할 수 있다.
- `.env`, 인증 키, 빌드 산출물, 로컬 원본 PDF와 평가용 정답은 기본 제외한다.

## 결과

- 별도 독립 실행기와 작업 큐는 첫 버전에서 제외된다.
- 인증 토큰을 추출하거나 애플리케이션 API 키로 재사용하지 않는다.
- 공식 Codex가 로그인과 갱신을 담당하는 경로를 전제로 후속 설계를 진행한다.
- 제외 자료가 필요해지는 경우 자동 확대하지 않고 별도 결정을 요구한다.
