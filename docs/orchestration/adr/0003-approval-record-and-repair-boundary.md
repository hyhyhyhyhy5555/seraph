# ADR 0003: 승인 기록과 자동 보수 경계

- 상태: 승인됨
- 날짜: 2026-11-22

## 맥락

승인 기반 오케스트레이터가 이전 세션의 결정을 재현하려면 채팅 밖의 지속 가능한 기록이 필요하다. 동시에 승인 후 발견되는 필수 테스트 변경과 예상하지 못한 기능 확장을 구분해야 한다.

## 결정

- 각 실행의 계획, 승인, 결과와 검증 증거를 `docs/orchestration/runs/`의 Markdown 문서로 남긴다.
- 승인된 목적에 직접 필요한 테스트와 개발 문서는 별도 승인 없이 함께 변경할 수 있다.
- 새로운 기능 영역으로 확장되면 멈추고 재승인을 요청한다.
- 같은 실패 원인의 자동 보수는 최대 두 번으로 제한한다.

## 결과

- 다른 세션에서도 승인 근거와 실제 결과를 확인할 수 있다.
- 파일 목록이 일부 달라져도 승인 목적 안의 필수 검증 변경은 진행할 수 있다.
- 무제한 수정과 숨은 범위 확대를 방지한다.
