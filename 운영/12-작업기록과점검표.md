# 12. 작업 기록과 전체 점검표

## 사용 방법

명령을 실행한 뒤 실제 관찰 결과를 적는다. 계획만 읽고 완료 체크하지 않는다. 비밀번호·API key·토큰·개인정보·private key는 이 문서에 넣지 않는다. 증적은 필요한 부분만 마스킹해 기록한다.


## 최종 출시 gate

### 서비스·네트워크

- [ ] 개발 서버 없이 API·DB 동작
- [ ] DB·관리 포트 WAN 차단
- [ ] 실제 HTTPS·LTE/5G 접속
- [ ] 인증서 자동 갱신·DNS 변경 복구
- [ ] Windows 재부팅 후 자동 복구

### 데이터·AI

- [ ] 허용된 원문·revision·출처 확인
- [ ] 로컬 모델·query/document 전처리 일치
- [ ] 외부 AI 호출 없음
- [ ] 검색 품질·무근거 질문·지연 평가
- [ ] DB·PDF·모델 복원 검증

### 보안·자동화

- [ ] 관리자 route·세션 소유권 보호
- [ ] 입력 제한·요청 제한·timeout
- [ ] 자체 Git·CI·Registry로 배포
- [ ] 빌드/배포 권한 분리
- [ ] secret 누출 없음
- [ ] 이미지 rollback·schema 호환 검증
- [ ] 디스크·백업·인증서 장애 감지

### 앱·스토어

- [ ] Android 서명 AAB·기기·Play 테스트
- [ ] iOS Mac Archive·TestFlight·기기
- [ ] 서명키·계정 복구 경로 확보
- [ ] 스토어 정보·개인정보 고지·지원 URL
- [ ] 양쪽 스토어 설치본에서 API 확인
- [ ] 다음 버전 업데이트 확인
