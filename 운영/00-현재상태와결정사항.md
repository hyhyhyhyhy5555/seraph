# 00. 현재 상태와 미정 사항

## 저장소에서 확인한 사실

| 항목 | 현재 상태 | 운영 전 작업 |
| --- | --- | --- |
| 앱 | Expo 57 / React Native, Expo Router | 실기기·릴리스 빌드 검증 |
| API | Express 5 / TypeScript | 접근 제어·요청 제한·배포 |
| DB | PostgreSQL 17, pgvector | 영구 볼륨·백업·역할 분리 |
| Node | `.nvmrc` 22.13.1 | 실행 시 지원·보안 상태 확인 후 버전 정책 확정 |
| Docker | 멀티스테이지 Dockerfile, node 사용자 | 이미지 취약점 확인·digest 고정 |
| Compose | API와 DB, DB 초기화 디렉터리 마운트 | 개발 기본 비밀번호 교체·포트 제한 |
| CI | GitHub Actions 검사·빌드·artifact | 자체 러너·자체 Git 워크플로로 이식 |
| 앱 배포 | eas.json preview/production | 자체 Android·Mac 빌드·서명 |
| 생존 검사 | GET /live | K8s liveness에 사용 |
| 준비 검사 | GET /health, DB select 1 | readiness에 사용, DB 상세 오류 외부 노출 개선 |
| AI | OpenAI SDK 기반 임베딩, 키 없으면 키워드 폴백 | 로컬 provider 구현·재임베딩 |
| DB 스키마 | 001~009 SQL | 적용 이력·checksum·잠금 관리 |

실행 당시 의존성·파일은 변경될 수 있으므로 작업 시작 때 다시 확인한다. 현재 작업 트리에는 이 문서 외의 기존 수정도 있다. 운영 문서 작성과 관련 없는 변경은 되돌리지 않는다.

## 구현이 필요한 중요한 차이

1. `src/lib/api.ts`의 API 주소는 `EXPO_PUBLIC_API_URL` 또는 localhost다. 휴대폰의 localhost는 휴대폰 자신이다. 출시 빌드에 실제 주소를 넣어야 한다.
2. `backend/src/env.ts`는 production에서 DB 정보와 CORS origin을 요구한다. 네이티브 앱만 배포해도 현재 설정 검사는 통과시켜야 한다.
3. `backend/src/embeddings.ts`는 API key와 OpenAI SDK에 묶여 있다. 문서의 로컬 모델을 설치하는 것만으로 연결되지 않는다.
4. vector 차원은 현재 1024다. 다른 차원의 모델은 스키마·인덱스·검색 함수·저장된 벡터를 함께 바꿔야 한다.
5. 관리 API는 공개 전에 인증·권한 검토가 필요하다. CORS는 인증이 아니다.
6. Dockerfile의 HEALTHCHECK는 Kubernetes probe를 자동 생성하지 않는다.
7. 기존 EAS 설정은 자체 빌드·서명을 대신하지 않는다.
8. PDF importer에는 `pdftotext`가 필요하다. 현재 API Dockerfile에는 별도 설치가 없다. importer 전용 이미지 또는 VM 도구가 필요하다.

## 향후 배포 값 기록표

아래 값은 예시도 실제 값으로 오인하지 않도록 비워 둔다.

- 서비스 VM IP: `<SERVICE_VM_IP>`
- 도구 VM IP: `<TOOLING_VM_IP>`
- 빌드 장비: 보유 MacBook. 그램 내 빌드 VM은 구성하지 않음.
- 게이트웨이 / LAN 대역: `<GATEWAY>` / `<LAN_CIDR>`
- API / 웹 / Git / Registry 호스트: 각각 `<API_HOST>` / `<WEB_HOST>` / `<GIT_HOST>` / `<REGISTRY_HOST>`
- 운영 namespace: `seraph-prod`; 테스트 namespace: `seraph-staging`
- Android package / iOS bundle ID: 미정, 공개 후 변경이 어려우므로 임시 값을 확정하지 않는다.
- K3s / Ubuntu / Docker / Gitea / cert-manager / 모델 버전: 설치 직전 검증 후 기록.

비밀번호·토큰·keystore 암호·Apple 인증서는 이 표에 적지 않는다. 보관 위치와 복구 담당자만 기록한다.

## 진행 원칙

미정 값이 필요한 단계는 그 단계만 보류하고 다른 문서를 준비한다. 확인된 RAM 16GB와 저장 공간 여유 약 39GB를 기준으로 VM 한 대부터 시작한다. VM 세 대·GPU 서버 구매를 전제로 확정하지 않는다. 기간은 계정 확인·장비·스토어 심사에 따라 달라지므로 고정 출시일을 약속하지 않는다.

## 실행 전 기준선 확인

맥북 개발 장비에서 저장소 루트 기준. 그램은 빌드를 실행하지 않는다:

```bash
git status --short
node --version
npm --version
cat .nvmrc
npm ci
npm run check
npm run build
```

의존성 감사는 `npm run audit:prod`로 실행한다. 실패 시 보고서를 확인해 원인을 해결하고, 자동 `--force` 업데이트로 Expo 호환성을 깨뜨리지 않는다. 결과·커밋·도구 버전을 작업 기록에 남긴다.
